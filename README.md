# Attendance Tracker Workspace

This project creates an attendance tracking workspace.

## Features

* Creates a new workspace directory.
* Clones required project resources.
* Sets up helper files and reports folder.
* Configures attendance warning and failure marks.
* Verifies Python installation.
* Checks workspace integrity.
* Archives progress on interruption (Ctrl+C).
* Cleans temporary files automatically.

## Usage

Run the script and follow the prompts.

Enjoy tracking attendance!
